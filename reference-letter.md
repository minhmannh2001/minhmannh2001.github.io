**Subject: Recommendation for Nguyen Minh Manh (Mike), Full-Stack Software Engineer**

Dear Hiring Manager,

I am writing to recommend Nguyen Minh Manh (Mike) for a Full-Stack Software Engineer role. Mike joined Geniee Vietnam in August 2025 as a full-stack Software Engineer on its SFA/CRM team. The team builds Geniee's sales management software and a web portal platform that large Japanese companies use to run member sites and events for their own customers. In my role at Geniee, Inc., I directly manage the SFA team at Geniee Vietnam and have worked closely with Mike. I recommend Mike without reservation.

One of Mike's main projects was a member portal and event platform for a Japanese bank, which Mike worked on from the first build in late 2025 through launch. Mike built the Zoom webinar integration from end to end, so that attendance at each webinar is recorded in the bank's customer records automatically. Mike also delivered two-step login that can be limited to specific organisations, embedded analytics dashboards, printable event pages, the public home page, and application forms that show different questions depending on earlier answers.

Mike then became the main developer on an online reservation portal for a Japanese theme park. Mike built its booking rules, including cancellation policies, booking deadlines and blocking of closed days, along with price calculation for large orders, file sharing between the portal and the customer's sales records, and a more reliable sync of data between the two systems. Mike also wrote about 29,000 lines of automated tests, made the portal's first page download more than 70% smaller, and halved the time Mike's code changes take to be reviewed and merged. In total Mike delivered 155 code changes and resolved 154 tasks, many of them direct customer requests. Using AI coding agents every day, Mike usually delivers a feature within two days once the requirements are agreed.

Mike takes a request from requirements to release without needing close supervision, and our product managers have thanked Mike for questions and suggestions that improved their specifications.

On the technical side, Mike works across the whole stack: React and TypeScript for the user interface, Node.js and GraphQL for the server, AWS for background processing, and Google Cloud for fast content delivery. Mike also removed a database bottleneck that slowed down page loading.

If you plan to build products, or a strong forward-deployed engineering team from the start in the AI-native era, I urge you to hire Mike. That end-to-end ownership is the core of forward-deployed work. I am happy to answer any questions.
